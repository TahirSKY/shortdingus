# Packaging — 3 titles, 3 thumbnails

1. Write **3 titles** with genuinely different angles (curiosity gap, bold claim, number/specific, contrarian). Under 60 characters, the key word in the first 3 words, no clickbait the video doesn't deliver.
2. Write **3 thumbnail concepts**: one clear subject, big contrast, ≤4 words of text, emotion readable at phone size. Generate each with `agent-create kind=image role=image name=thumb-A.png` (then B, C).
3. Save `packaging.md` in the project (`role=plan`) listing titles A/B/C and thumbnails A/B/C.
4. Learning: if the hub has earlier `packaging.md` files with results noted (views/CTR), prefer the winning patterns and say which pattern you reused.
