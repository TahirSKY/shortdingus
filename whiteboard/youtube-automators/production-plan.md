# YouTube Automators: production plan

## Direction
Visual storytelling is the star. Follow the user's two reference images: clean expressive black marker ink, white ground, restrained blue / golden ochre / sage. Do not default to a character in every scene. Use purposeful visual metaphors, clean compositions and varied camera-scale; characters appear only for the maker and candid founder beats. Reserve exact wording, platform UI and offer text for code overlays, not baked-in image text. The supplied voiceover is retained as-is.
