🧠 Yappucino Trick - Force Continuous Talking (No Pauses)

Problem: Video models pause - start talking, stop, start. Kills yappucino flow.

Solution: Long script > clip duration
If clip is 8 sec, give it a sentence that takes 12 sec to say. Model is forced to start talking at frame 0 and yap continuously to fit it in. No pauses.

Example: Instead of "Elon Musk." (1 sec, will pause) →
"Elon Musk son of a man who owned an emerald mine in apartheid South Africa and Jeff Bezos parents invested two hundred fifty thousand dollars..." (12 sec, forces continuous yapping)

Also: In base image, mouth slightly open mid-speech avoids conflict. If base image has closed mouth and you prompt "talking", model conflicts. Open mouth base = smooth talking video.

🎙️ Mic vs Camera

Don't prompt "holding camera" - model shows physical camera object (defected). Instead:

- For POV (viewer = camera): "POV first-person, hand reaching toward lens, NO camera object visible, viewer is camera"
- For interview: "holding microphone, someone else filming, interview style" - mic indicates crew, no camera object needed
- For office: No mic, no camera, just talking - legendary pause, natural
